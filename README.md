## Overview
This project demonstrates how JavaScript can interact with HTML elements to dynamically update webpage content based on user input. Users can enter a username into a text field and submit it to display a personalized greeting.

## Features
- Accepts user input through an HTML text field.
- Uses a button click event to trigger JavaScript functionality.
- Retrieves the entered value from an HTML input element.
- Dynamically updates a heading using the `textContent` property.
- Displays a personalized greeting without requiring a page reload.

## Languages Used
- HTML
- CSS
- JavaScript

## Project Structure
- `professional.html` — Defines the webpage structure, input field, and submit button.
- `professional.js` — Handles user input and dynamically updates the webpage.
- `style.css` — Defines the webpage's visual styling.

## Learning Objectives
- Practice DOM manipulation in JavaScript.
- Access HTML elements using `document.getElementById()`.
- Retrieve values from HTML input fields.
- Handle button click events.
- Dynamically modify webpage content using `textContent`.
